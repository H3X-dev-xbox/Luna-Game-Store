## 🚀 The Vision

<img src="https://readme-typing-svg.demolab.com?font=Fira+Code&size=16&duration=2500&pause=1000&color=00D9FF&center=true&vCenter=true&width=600&lines=Steam.+Xbox+Cloud.+GOG.;Take+the+best+of+all+three.;Then+make+it+better." alt="Vision" />

</div>

**Luna Game Store** is a next-generation game launcher and storefront built for players who are tired of bloated platforms, aggressive monetization, and cluttered interfaces.

We're building something **cleaner**, **faster**, and **freer** — a store that respects the player, celebrates indie developers, and treats game discovery as an art form rather than an algorithm.

### 🌌 What Makes Luna Different

| | Luna Game Store | Traditional Stores |
|---|---|---|
| 💸 **Cost** | Free forever | Free + 30% cuts |
| 🎨 **Design** | Galaxy-themed, minimal, modern | Cluttered storefronts |
| ⚡ **Speed** | Lightweight launcher | Heavy background services |
| 🔓 **Openness** | Built with community feedback | Corporate black box |
| 🎮 **Focus** | Players & indie devs first | Shareholders first |
